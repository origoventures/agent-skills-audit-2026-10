# Adversarial review, 11 October 2026

Before publication, six independent reviewers attacked this repository and the article, each from one angle:

1. reproducibility engineer;
2. software supply-chain security researcher;
3. empirical-methods reviewer;
4. Claude Code platform expert;
5. senior editor of a Medium AI publication;
6. maintainers of the named projects (claude-seo, impeccable, last30days, caveman, codex-plugin-cc).

All six were AI agents. Each started from a fresh clone of this repository, cloned the audited projects itself at the listed commits, and executed nothing from them. The author re-checked their main points against the source.

## What was checked

- **Script.** `audit.py` reproduced `audit.csv` (except live tag counts) and `evidence.json` byte for byte on ext4.
- **Commits.** All 20 full SHAs resolve and are consistent across files. All 20 were HEAD of their default branch in the same window on 8 October.
- **Counts.** Every count in the article was rebuilt from `classification.csv` (see the table in the README).
- **Churn.** The churn figures (11 of 20 changed, 9 in code) were re-derived from `git diff`, including superpowers 6.4.2 to 7.0.0.
- **Dates.** The claude-seo mod dates and impeccable's engine pins.
- **Official marketplace.** The pins as of 8 October (`official-marketplace-pins.csv`).
- **Sample.** Source articles and byline dates in `SAMPLE.md`.
- **Citations.** Liu et al. (arXiv 2601.10338: 31,132 skills, odds ratio 2.12) and Snyk ToxicSkills (3,984 skills, 13.4%, 76 confirmed malicious payloads).
- **Documentation quotes.** All quotes from the Claude Code documentation are verbatim and current.

## Points the reviewers asked to make explicit

These are reflected in the classification notes, the README and the article:

- **Sample.** It is a convenience sample from three articles, half of the third-party projects from one of them.
- **Main install paths.** impeccable's is `npx impeccable install`, which installs a signed skill bundle; caveman's writes about ten hook events into `~/.claude/settings.json`; claude-seo's docs pipe the installer from `main` for install and upgrade.
- **claude-seo mod.** It ships in a separate optional plugin, holds or asks, and never approves a call.
- **impeccable binary.** It is built by the project's CI from source in the same repository; the checksum comes from the same release.
- **Data flows.** The Codex plugin's `codex-rescue` subagent can be used proactively; graphify picks a model provider from the keys it finds.
- **Pins.** The official marketplace pin decides who moves the version, not whether it moves: that marketplace auto-updates by default.
- **Admin controls.** `allowManagedModsOnly` is an option of the built-in guard under `pluginConfigs`; `disableSideloadFlags` is needed to stop `--plugin-dir`; installers that write settings files are not covered by plugin controls.
- **Reproducibility caveats.** `audit.py` walks directories in filesystem order and writes 0 tags silently when offline. Both are documented in the README; the script is kept exactly as run on 8 October.
- **AI disclosure.** The article states in its opening that the analysis was done by AI agents and the text written with AI assistance.
